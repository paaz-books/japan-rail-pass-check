# Rail Pass Check

List the train rides in your Japan trip and compare a Japan Rail Pass, regional passes and single tickets for everyone traveling. Each pass is placed on the run of days where it covers the most. A companion to paaz's guide to a first trip to Japan.

- Check: https://paaz-books.github.io/japan-rail-pass-check/
- `index.html`: the whole tool in one file (fares and pass prices as of September 30, 2026)
